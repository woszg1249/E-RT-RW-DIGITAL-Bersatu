1. HTMLSPECIALCHARS AUDIT (PRIORITAS MEDIUM)
   
   Grep menemukan 92 instance "echo $" di 19 file yang perlu dicek.
   
   File yang perlu dicek XSS protection:
   - dashboard.php (echo session/user data)
   - profil.php (echo user data)
   - kelola_warga.php (echo data warga dalam tabel)
   - kelola_kk.php (echo data keluarga)
   - kelola_tagihan.php (echo data tagihan)
   - posyandu.php (echo data posyandu)
   - bank_sampah.php (echo data bank sampah)
   - kegiatan.php (echo data kegiatan)
   - koperasi.php (echo data koperasi)
   - umkm.php (echo data UMKM)
   - laporan.php (echo data laporan)
   - includes/header.php (echo username, role)
   - includes/sidebar.php (echo menu items)
   
   Cara perbaiki:
   Ganti: echo $row['nama'];
   Jadi:  echo htmlspecialchars($row['nama'], ENT_QUOTES, 'UTF-8');
   
   KECUALI untuk:
   - Konstanta (echo $base_url)
   - Angka dari database yang sudah di-cast (echo (int)$row['jumlah'])
   - HTML yang sengaja (rare case, pakai strip_tags jika perlu)

3. SQL COMMANDS UNTUK DATABASE
   
   Jalankan di HeidiSQL sebelum deployment:
   
   A. Pastikan kolom password cukup besar untuk hash:
      
      ALTER TABLE users MODIFY COLUMN password VARCHAR(255);
   
   B. (OPSIONAL) Jika ingin menambahkan kolom untuk token reset:
      
      ALTER TABLE users 
      ADD COLUMN reset_token VARCHAR(64) DEFAULT NULL,
      ADD COLUMN reset_token_expires DATETIME DEFAULT NULL,
      ADD INDEX idx_reset_token (reset_token);
   
   C. Pastikan tabel transaksi_pembayaran ada kolom untuk webhook:
      
      -- Cek struktur tabel, pastikan ada:
      -- id, order_id, id_user, jumlah, status, payment_type, 
      -- transaction_time, settlement_time, created_at

4. FILE .htaccess UNTUK FOLDER img/
   
   Buat file img/.htaccess dengan isi:
   
   <FilesMatch "\.(php|php3|php4|php5|phtml|phps)$">
       Require all denied
   </FilesMatch>
   <FilesMatch "\.(jpg|jpeg|png|gif|webp|svg|ico)$">
       Require all granted
   </FilesMatch>
   php_flag engine off
   Options -Indexes
   <Files .htaccess>
       Require all denied
   </Files>

5. SSL/HTTPS DI HOSTING
   
   Tambahkan .htaccess di root (jika hosting support):
   
   RewriteEngine On
   RewriteCond %{HTTPS} off
   RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]

6. PERMISSION FILE DI HOSTING
   
   Via FTP atau cPanel File Manager:
   - Semua folder: 755 (drwxr-xr-x)
   - Semua file .php: 644 (-rw-r--r--)
   - Koneksi.php: 600 atau 644
   - Folder img/: 755 dan writable
